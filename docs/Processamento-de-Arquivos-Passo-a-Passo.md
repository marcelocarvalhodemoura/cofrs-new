# Processamento de Arquivos (Passo a passo para iniciantes)

Este guia explica, de forma simples, como acompanhar o processamento dos arquivos de retorno (ex.: IPE e Tesouro do Estado) dentro do sistema.

## 1) Envio do arquivo
- Na tela de Convênios, envie o arquivo `.xlsx` ou `.txt` normalmente, escolhendo o convênio e a competência.
- Ao finalizar o envio, o sistema registra o arquivo e começa o processamento.

## 2) Onde acompanhar
- Acesse: Menu → Processamento de arquivos.
- Você verá uma lista de arquivos enviados, com:
  - Competência (mês/ano)
  - Convênio (ex.: ipe, tesouro)
  - Tipo (xlsx ou txt)
  - Responsável (quem enviou)
  - Data/hora de envio e de última atualização
  - Status do processamento

## 3) Status e barra de progresso
- Aguardando: o arquivo está na fila para ser processado.
- Processando: aparece uma barra de progresso com percentual (%), além de:
  - Decorrido ~ N min (tempo já gasto)
  - Restante ~ M min (previsão de quanto falta)
  - Erros: X (quantas linhas com problema foram encontradas até agora)
- Concluído: processamento finalizado. Você pode ver os detalhes.
- Cancelado: processamento interrompido por quem solicitou.

Observação: os tempos são estimativas. Eles podem variar dependendo do tamanho do arquivo e do movimento no sistema.

## 4) Ações disponíveis
- Detalhes: abre uma janela com as primeiras linhas do arquivo, mostrando por linha:
  - Número da linha
  - Status (OK, Erro ou Pendente)
  - Contrato / Matrícula / Referência
  - Mensagem (ex.: motivo de erro ou confirmação de sucesso)
- Cancelar: interrompe o processamento do arquivo (somente enquanto estiver aguardando ou processando).
- Reprocessar: coloca o arquivo novamente na fila, descartando os resultados anteriores.

## 5) Como interpretar os números
- Percentual: mostra a parte já processada do total de linhas do arquivo.
- Erros: conta de linhas com problema (ex.: linha não encontrada, dados inválidos, etc.).
- Dica: use o botão Detalhes para identificar rapidamente onde estão os erros.

## 6) Notificações
- Ao concluir o processamento, o sistema mostra um aviso na tela (e também envia e-mail).
- Você pode continuar usando o sistema normalmente enquanto o arquivo é processado.

## 7) Dúvidas comuns
- Posso fechar a página? Sim. O processamento continua no servidor. Ao voltar na lista, a barra será atualizada.
- O que fazer se houver muitos erros? Clique em Detalhes, verifique as mensagens e, se necessário, corrija o arquivo de origem e use Reprocessar.
- O recurso funciona para quais convênios? Vale para IPE e Tesouro do Estado, e pode ser usado por futuros convênios também.
